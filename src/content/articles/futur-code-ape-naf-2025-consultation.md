Le **14 janvier 2026**, l’Insee a annoncé que chaque entreprise pouvait consulter, sur le site sirene.gouv.fr et avec son numéro SIREN, le code APE qui lui sera attribué au **1er janvier 2027**. Ce nouveau code découle de la révision de la nomenclature d’activités françaises, dite NAF 2025.

## Ce qui a été annoncé

D’après le communiqué de l’Insee et ses relais institutionnels (à relire sur les pages citées) :

- le code APE actuel reste le seul code officiel pendant toute l’année 2026 ;
- le futur code est consultable dès maintenant, en saisissant le SIREN de l’entreprise ;
- la bascule se fera pour toutes les unités du répertoire Sirene au 1er janvier 2027 ;
- selon les relais officiels, ce changement de code ne crée par lui-même ni droit ni obligation nouvelle.

## Ce que cela change pour vous

Le code APE sert surtout à classer l’activité à des fins statistiques. Mais il est recopié dans beaucoup de documents et sert parfois de repère à des tiers : un organisme, un assureur, un financeur ou un partenaire peut s’y référer pour une première orientation. Un code qui ne correspond plus à l’activité réelle, c’est une source de questions, voire de malentendus.

L’intérêt de l’annonce du 14 janvier est de laisser une année entière pour vérifier, et demander une correction si nécessaire, avant que le nouveau code ne s’applique.

## Checklist en dix minutes

1. Consulter le futur code APE sur sirene.gouv.fr avec le SIREN de l’entreprise.
2. Lire l’intitulé de ce code et le comparer à l’activité principale réellement exercée.
3. En cas d’écart, se renseigner auprès de l’Insee sur la procédure de demande d’examen.
4. Lister les documents qui citent le code actuel : extrait d’immatriculation, contrats d’assurance, dossiers de financement, pages du site internet.
5. Ranger une capture de la consultation dans le [dossier permanent de l’entreprise](/guides/dossier-permanent-entreprise), avec la date.
6. Inscrire dans l’[échéancier administratif](/guides/echeancier-administratif-entreprise) un rappel en janvier 2027 pour mettre à jour ces documents.

## Exemple fictif : la paysagiste devenue formatrice

Une paysagiste a progressivement transformé son activité : la formation représente désormais l’essentiel de son chiffre d’affaires. En consultant son futur code, son assistante constate qu’il décrit toujours l’entretien d’espaces verts. Elles notent la question pour l’expert-comptable et se renseignent sur la démarche de modification. Le cas est inventé pour illustrer l’intérêt de la vérification.
