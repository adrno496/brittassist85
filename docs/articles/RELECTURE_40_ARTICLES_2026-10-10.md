## S01 — Appels masqués depuis l’étranger : le changement de 2026

Actualité : 2026-01-01. Circuit : standard. [Fiche Markdown](../../src/content/articles/numero-masque-appels-etranger-janvier-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/numero-masque-appels-etranger-janvier-2026).

Depuis janvier 2026, certains appels légitimes depuis l’étranger apparaissent masqués. Organisez le filtrage sans perdre les messages de vos clients.

Depuis le 1er janvier 2026, un appel provenant de l’étranger et présentant un numéro mobile français peut apparaître masqué si ce numéro n’a pas pu être authentifié. L’Arcep avait annoncé cette mesure le 2 décembre 2025 pour limiter l’usurpation de numéros.

Un client en déplacement peut donc vous appeler sans que son numéro habituel s’affiche. Ce signal doit inviter à vérifier l’identité de l’interlocuteur, sans conclure automatiquement que l’appel est malveillant.

## Ce que cela change pour vous

Si votre entreprise bloque tous les appels anonymes, regardez ce que devient un message laissé par un client à l’étranger. Le risque pratique est de confondre filtrage et absence de suivi : personne ne consulte le répondeur, le client rappelle plusieurs fois et le dirigeant découvre trop tard une question urgente.

Préférez une consigne simple : recueillir un nom, une entreprise, un motif et un moyen de rappel. Pour une demande sensible, utilisez ensuite une coordonnée déjà présente dans votre fichier clients. Le numéro donné pendant l’appel ne suffit pas, à lui seul, à confirmer une identité.

## Adapter les consignes d’accueil

Le message du répondeur peut demander de préciser le nom et l’objet de l’appel. Évitez d’inviter à dicter un mot de passe, un code de validation ou des informations bancaires. L’accueil transmet seulement les éléments nécessaires à une réponse.

Convenez aussi d’un canal de secours avec les clients qui voyagent régulièrement : un courriel sur leur adresse connue, par exemple. Cette organisation relève de votre fonctionnement interne ; la décision de l’Arcep ne crée pas une nouvelle procédure obligatoire d’accueil pour votre entreprise.

## Checklist pour les appels internationaux

1. Vérifier le réglage de blocage des appels anonymes et le fonctionnement du répondeur.
2. Confier la lecture des messages à une personne identifiée, avec un remplaçant.
3. Préparer une courte fiche de message : appelant, entreprise, objet, urgence annoncée.
4. Rappeler sur une coordonnée connue lorsque la demande touche un paiement ou un accès.
5. Informer les clients concernés du canal à utiliser si leur appel n’aboutit pas.
6. Tester le circuit avec un appel masqué et vérifier que le message arrive au bon destinataire.

## Exemple fictif : un fournisseur en déplacement

Un fournisseur habituel appelle depuis l’étranger pour signaler une livraison décalée. Son numéro est masqué. L’assistante recueille le message puis confirme le changement par l’adresse professionnelle déjà enregistrée. Elle note le nouvel horaire dans le planning. Ce cas inventé montre comment garder le contact tout en vérifiant la demande.

Le même réflexe est utile si l’appel annonce un nouveau RIB : la vérification doit précéder tout changement de paiement, même si l’interlocuteur connaît votre dossier.

## S02 — Code APE 2027 : consulter le futur classement

Actualité : 2026-01-14. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/futur-code-ape-naf-2025-consultation.md). [Aperçu local](http://127.0.0.1:4322/articles/futur-code-ape-naf-2025-consultation).

L’Insee permet de consulter votre futur code APE depuis janvier 2026. Vérifiez le classement proposé et préparez vos documents sans modifier le code officiel de 2026.

Le communiqué de l’Insee daté du 14 janvier 2026 ouvre une étape de préparation : les entreprises peuvent consulter sur sirene.gouv.fr le code APE qui leur sera attribué à partir du 1er janvier 2027. La nouvelle nomenclature NAF vise à mieux représenter les activités économiques actuelles.

Toutes les unités inscrites à Sirene sont concernées, y compris les micro-entrepreneurs. En revanche, pendant 2026, le code APE actuel demeure le code officiel. Consulter un futur classement ne signifie donc pas qu’il faut déjà remplacer celui qui figure dans vos dossiers.

## Ce que cela change pour vous

Cette consultation donne du temps pour repérer un classement qui semblerait ne pas correspondre à l’activité principale réellement exercée. L’Insee prévoit un formulaire en ligne pour demander une expertise du futur code si nécessaire.

Le travail administratif consiste à rassembler des éléments factuels : description de l’activité, répartition des prestations et documents de l’entreprise. Il faut éviter de décrire une activité souhaitée pour obtenir un classement particulier. Le code APE est un repère statistique ; l’Insee précise que son changement ne crée pas, par lui-même, de droit ou d’obligation supplémentaire.

## Conserver deux repères sans confusion

Dans le dossier permanent, créez une note distincte avec le code actuel, le futur code proposé, la date de consultation et l’éventuelle demande d’expertise. Intitulez clairement le second « futur code, applicable en 2027 ».

Recensez ensuite les supports où l’information est utilisée : logiciels de gestion, fiches fournisseurs ou dossiers de candidature. Ce recensement prépare une mise à jour ultérieure ; il ne dispense pas de vérifier ce que chaque organisme demandera effectivement au moment du changement.

## Checklist pour préparer janvier 2027

1. Retrouver le SIREN de l’entreprise dans un document officiel.
2. Consulter le futur code sur le site Sirene, en accédant directement au service.
3. Comparer le libellé avec l’activité principale exercée.
4. Conserver le résultat et sa date dans une note identifiable.
5. Si le classement paraît incohérent, rassembler les éléments pour une demande d’expertise.
6. Programmer une vérification au début de 2027 avant les mises à jour des dossiers.

## Exemple fictif : une activité qui a évolué

Une entreprise développe aujourd’hui surtout des prestations numériques alors que son dossier décrit encore une ancienne activité commerciale. Sa dirigeante demande à son assistante de réunir les informations utiles. L’expertise du classement est demandée à l’Insee ; aucun code n’est changé arbitrairement sur les documents de 2026. Ce cas est inventé.

Gardez la réponse de l’organisme avec la demande initiale. Une trace complète facilite le suivi si le dossier change de mains.

## S03 — Plateformes agréées : comparer la liste de janvier 2026

Actualité : 2026-01-16. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/liste-plateformes-agreees-facturation-electronique.md). [Aperçu local](http://127.0.0.1:4322/articles/liste-plateformes-agreees-facturation-electronique).

La première liste de 101 plateformes agréées a été publiée en janvier 2026. Comparez les usages, le contrat et les accès avant de choisir votre outil.

Le 16 janvier 2026, le ministère de l’Économie a annoncé une première liste de 101 plateformes agréées pour la facturation électronique. Cette liste fournit un point de départ fiable pour identifier les acteurs reconnus dans le dispositif.

Le nombre annoncé décrit la situation de janvier. Pour un choix effectué aujourd’hui, consultez la liste officielle actualisée : un article rétrospectif ne remplace pas la vérification du statut actuel d’un prestataire.

## Ce que cela change pour vous

Votre comparaison peut commencer par les besoins réels de l’entreprise : recevoir des factures, retrouver les pièces, suivre les statuts et travailler avec l’expert-comptable. Une plateforme présente dans une liste officielle n’offre pas nécessairement le même accompagnement, les mêmes fonctions ou le même prix qu’une autre.

Posez une question précise à l’éditeur de votre logiciel actuel : passe-t-il par une plateforme agréée, laquelle, et que comprend votre abonnement ? Conservez sa réponse. Un intitulé commercial comme « compatible avec la réforme » mérite d’être traduit en services et responsabilités identifiables.

## Préparer une comparaison utilisable

Rassemblez quelques factures représentatives, sans transmettre inutilement les coordonnées personnelles de vos clients lors d’une démonstration. Notez leur origine, les personnes qui les traitent et la façon dont elles arrivent au cabinet comptable.

Demandez ensuite une proposition écrite précisant le périmètre, la durée d’engagement, les accès disponibles et les conditions de sortie. La comparaison doit inclure le fonctionnement quotidien : qui voit une facture reçue, qui corrige une erreur et comment l’entreprise récupère ses données.

## Checklist avant le choix de plateforme

1. Vérifier l’acteur sur la liste officielle en vigueur au jour du choix.
2. Identifier les flux traités par le logiciel et ceux qui restent à organiser.
3. Faire participer la personne chargée des factures et l’expert-comptable.
4. Tester une réception et l’accès à une pièce avec un dossier de démonstration.
5. Obtenir le tarif complet et les conditions contractuelles par écrit.
6. Désigner le responsable des comptes et prévoir les accès des remplaçants.

## Exemple fictif : deux propositions difficiles à comparer

Une TPE reçoit une offre intégrée à son logiciel et une offre séparée. Son assistante construit un tableau avec les fonctions nécessaires, les coûts annoncés et les conditions de récupération des données. Le dirigeant décide après validation du circuit avec son comptable. Cette situation est inventée et ne recommande aucun fournisseur.

Évitez de choisir sur le seul nombre de fonctions. Une fonction inutile peut compliquer le traitement, alors qu’un accès correctement attribué ou une assistance joignable répond à un besoin immédiat.

## S04 — Fichier clients et publicité : la sanction CNIL de janvier

La CNIL a sanctionné un transfert de données clients vers un réseau social. Avant un import publicitaire, vérifiez le consentement, la finalité et les preuves.

Le 22 janvier 2026, la CNIL a rendu publique une sanction de 3,5 millions d’euros concernant la transmission de données d’un programme de fidélité à un réseau social pour du ciblage publicitaire. La décision avait été prononcée le 30 décembre 2025.

Cette affaire rappelle qu’un fichier constitué pour gérer une relation client ne peut pas être utilisé sans examen pour une autre opération. L’existence d’une adresse électronique dans votre logiciel ne prouve pas que la personne a accepté un transfert à un réseau social.

## Ce que cela change pour vous

Avant de lancer une campagne fondée sur un import de contacts, identifiez les données envoyées, leur provenance et la finalité exacte. Demandez également quelles informations ont été données aux clients et quelles preuves de consentement sont conservées pour cet usage.

## Préparer le dossier avant l’import

Séparez les contacts selon leur origine. Un client, un participant à un événement et un abonné à une lettre d’information peuvent avoir reçu des informations différentes. Une colonne « accord » dépourvue de date ou de contenu associé ne permet pas de comprendre ce qui a été accepté.

Préparez un dossier comprenant le formulaire utilisé, la notice d’information applicable à cette époque, le circuit du consentement et le contrat du prestataire. Faites examiner les questions de base légale et de transfert par votre référent compétent avant l’activation de la campagne.

## Checklist pour un fichier publicitaire

1. Décrire l’opération envisagée et les destinataires des données.
2. Identifier l’origine de chaque lot de contacts.
3. Vérifier le consentement requis et la preuve disponible pour l’utilisation envisagée.
4. Retirer les personnes dont l’opposition ou le retrait doit être pris en compte.
5. Obtenir les explications et documents du prestataire.
6. Faire valider le traitement avant tout export, puis limiter les données transmises.

## Exemple fictif : le fichier d’une boutique

L’import est suspendu le temps de vérifier les conditions du nouveau traitement. Ce cas est inventé : il illustre une vérification préalable, sans conclure à la conformité d’un formulaire particulier.

L’assistante peut préparer cet inventaire et suivre les corrections décidées. Elle n’a pas à tester des mots de passe ni à consulter des dossiers pour lesquels elle n’est pas habilitée. Une vérification doit respecter les mêmes limites que le travail quotidien.

## Checklist des accès partenaires

1. Recenser les comptes attribués aux intervenants extérieurs.

4. Faire examiner l’authentification et la détection des connexions inhabituelles.
5. Retirer les droits devenus inutiles après validation du responsable.
6. Conserver la date de la revue et les actions restant à terminer.

6. Mettre à jour le suivi après chaque règlement, réponse ou livraison.

Leur installation mérite cependant un cadrage précis. Un outil destiné à bloquer des sites dangereux peut aussi produire des informations sur la navigation des personnes. Il faut comprendre quelles données sont enregistrées et à quelles fins elles servent.

Le prestataire explique ensuite le fonctionnement, les exceptions et la gestion des alertes. Faites distinguer un blocage de sécurité d’un problème d’accès ordinaire. Un utilisateur doit savoir à qui demander une vérification lorsqu’un site utile à son travail devient inaccessible.

## Checklist avant l’installation ou la revue

1. Définir le besoin de sécurité et les équipements concernés.
2. Demander quelles données sont lues et enregistrées.
3. Faire examiner les opérations plus intrusives, notamment sur les communications chiffrées.
4. Identifier les accès aux journaux, la conservation et le circuit des alertes.
5. Préparer l’information des utilisateurs avec le responsable compétent.
6. Tester le fonctionnement sur des sites professionnels nécessaires et prévoir une demande d’exception.

## Ce que cela change pour vous

La direction doit connaître ce qui est réellement capté, transmis et enregistré aujourd’hui, et faire examiner toute incertitude par son interlocuteur compétent.

## Checklist du dossier vidéoprotection

1. Repérer les équipements situés dans les espaces accessibles au public.
2. Identifier les microphones et les fonctions audio disponibles.
3. Obtenir la confirmation des fonctions réellement activées.
4. Vérifier les interconnexions avec d’autres équipements sonores.
5. Faire analyser les usages particuliers avant leur mise en œuvre.
6. Mettre à jour le dossier de réglages et les consignes destinées aux utilisateurs autorisés.

## Checklist des trois priorités

1. Identifier les comptes dont la perte d’accès arrêterait l’activité.
2. Faire vérifier leur protection et les moyens de récupération.
3. Écrire la procédure de validation d’un changement de coordonnées bancaires.
4. Localiser les sauvegardes et confirmer qui peut restaurer une pièce.
5. Tester un scénario simple avec les personnes concernées.

## Checklist du premier dossier d’entreprise

1. Identifier les documents officiels déjà reçus et ceux encore attendus.
2. Classer séparément simulations, demandes et décisions définitives.

4. Vérifier les pièces nécessaires avant le premier devis ou contrat.

## Checklist pour la veille des marchés

2. Vérifier les comptes et les adresses de réception des alertes.
3. Préparer l’accès à PLACE si ce canal concerne vos acheteurs.
4. Suivre le calendrier officiel de l’élargissement sans présumer une bascule immédiate.
5. Pour chaque consultation, relire les consignes et le canal exact de dépôt.
6. Tester l’organisation de remplacement avant une échéance importante.

## S31 — IA et transparence : vérifier les usages depuis août

Actualité : 2026-08-02. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/ai-act-transparence-chatbot-2-aout-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/ai-act-transparence-chatbot-2-aout-2026).

La Commission européenne a rappelé les règles de transparence applicables le 2 août 2026. Examinez vos chatbots et contenus générés avec les responsables concernés.

Le 31 juillet 2026, la Commission européenne a présenté les règles de transparence liées à l’IA applicables à partir du 2 août. Son annonce cite notamment l’information des personnes lorsqu’elles interagissent avec un chatbot et certains contenus générés ou manipulés artificiellement.

Les obligations diffèrent selon le rôle de l’acteur et le type de contenu. Cette annonce ne signifie pas qu’un même avertissement doit être ajouté indistinctement à tous les textes assistés par une IA.

## Ce que cela change pour vous

Si votre site propose un assistant conversationnel, vérifiez ce que voit la personne qui l’utilise. Le visiteur doit pouvoir comprendre la nature de l’interaction et savoir comment joindre un interlocuteur humain lorsqu’une réponse demande un examen particulier.

Recensez aussi les images, vidéos et autres contenus artificiels utilisés par l’entreprise. Les contenus manipulés, les obligations du fournisseur et l’information à apporter au public doivent être examinés dans leur contexte. Demandez une analyse adaptée à vos usages plutôt que de copier une mention générique.

## Préparer la vérification avec le fournisseur

Rassemblez le contrat, les paramètres et des captures du parcours public. Vérifiez la présence de l’information sur mobile autant que sur ordinateur. Une mention prévue dans la documentation du fournisseur n’est pas nécessairement visible dans votre propre intégration.

L’assistante peut inventorier les usages et tester le parcours, sans transmettre de dossiers clients sensibles à l’outil. Le responsable de la publication et le référent compétent valident les mentions, les limites du service et les procédures de reprise humaine.

## Checklist des usages visibles au public

1. Lister les chatbots et contenus artificiels utilisés par l’entreprise.
2. Identifier le fournisseur, le rôle de l’entreprise et la fonction concernée.
3. Lire la documentation actuelle et les règles applicables à cet usage.
4. Vérifier les informations réellement visibles dans le parcours.
5. Tester le passage vers une personne et les limites des réponses automatiques.
6. Conserver les décisions, les captures et les dates de modification.

## Exemple fictif : un chatbot d’accueil

Une entreprise installe un chatbot pour orienter les visiteurs. Son assistante teste le premier écran et constate que la nature automatique du service est peu visible sur mobile. Le responsable fait examiner l’information et la configuration avant de valider le parcours. Cette situation est inventée.

Après une évolution du fournisseur, refaites le test. Le dossier doit décrire le service accessible au public, pas uniquement celui qui avait été prévu lors de la première installation.

## S32 — Démarchage téléphonique : revoir les fichiers particuliers

Actualité : 2026-08-11. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/demarchage-telephonique-consentement-11-aout-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/demarchage-telephonique-consentement-11-aout-2026).

Depuis le 11 août 2026, le démarchage téléphonique des consommateurs est encadré par le consentement préalable et des exceptions. Vérifiez vos campagnes.

Depuis le 11 août 2026, le démarchage téléphonique des consommateurs repose sur le consentement préalable, sous réserve des exceptions prévues. Service Public avait annoncé ce changement le 21 juillet, puis actualisé sa publication au démarrage.

Cette actualité concerne les appels de prospection vers des particuliers. Elle ne doit pas être transformée en une interdiction générale de tous les appels entre professionnels, ni appliquée sans examen à un appel de service concernant un contrat.

## Ce que cela change pour vous

Avant une campagne, identifiez la qualité des personnes appelées, la raison de l’appel et la preuve disponible lorsque leur consentement est requis. La source décrit notamment une exception liée à un contrat en cours et à son objet ; elle ne permet pas d’utiliser n’importe quelle relation passée pour prospecter.

Faites examiner les conditions de collecte, la durée et le retrait du consentement par votre responsable compétent. Le fichier doit permettre de distinguer un accord encore utilisable d’un refus ou d’une information trop vague pour établir ce qui a été accepté.

## Revoir les consignes et le prestataire

Si les appels sont confiés à un prestataire, demandez l’origine des listes et les éléments permettant de vérifier le cadre des appels. Ne vous contentez pas d’une promesse globale de conformité dans une offre commerciale.

Préparez une consigne claire pour enregistrer une opposition et la transmettre avant le prochain appel. Les horaires et les autres limites applicables doivent aussi être vérifiés dans les instructions actuelles. L’assistante peut préparer le suivi ; elle ne qualifie pas seule une exception juridique.

## Checklist avant une campagne téléphonique

1. Distinguer les consommateurs des contacts professionnels.
2. Définir l’objectif et le périmètre de la campagne.
3. Vérifier le consentement requis ou l’exception examinée pour chaque lot.
4. Écarter les refus et les contacts dont la situation n’est pas établie.
5. Contrôler les instructions, les horaires et le suivi du prestataire.
6. Conserver les preuves et tester la prise en compte d’un retrait.

## Exemple fictif : un ancien fichier de prospects

Une entreprise souhaite rappeler des particuliers présents dans une ancienne liste. Son assistante retrouve les formulaires et les dates de collecte. Le responsable fait examiner les conditions d’utilisation ; les contacts insuffisamment documentés ne sont pas intégrés à la campagne en attendant la clarification. Ce scénario est inventé.

Gardez la trace des décisions de sélection. Le même fichier ne doit pas être réimporté plus tard en rétablissant, par erreur, des personnes qui avaient été retirées.

Utilisez-le avec les décisions confirmées par vos interlocuteurs, puis attribuez une prochaine action aux points qui restent ouverts.

## S33 — Piratage des impôts : vérifier les messages reçus

Actualité : 2026-08-18. Circuit : standard. [Fiche Markdown](../../src/content/articles/piratage-impots-vigilance-messages-aout-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/piratage-impots-vigilance-messages-aout-2026).

La CNIL a signalé en août 2026 des vérifications après un piratage fiscal. Face à un message utilisant des informations exactes, vérifiez le canal officiel.

Le 18 août 2026, la CNIL a publié un point sur le piratage du système d’information des impôts annoncé par le ministère le 14 août. Elle indique avoir reçu des notifications et poursuivre ses vérifications.

Les informations présentées à cette date mentionnent notamment des données fiscales et d’entreprise. La publication exprime aussi des réserves sur les éléments qui ne seraient pas concernés. Un bilan provisoire ne doit pas être transformé en certitude sur un dossier individuel.

## Ce que cela change pour vous

Un message frauduleux peut utiliser une référence réelle de l’entreprise pour paraître authentique. Le SIREN, le nom commercial ou une information fiscale exacte ne suffisent donc pas à valider la demande de l’expéditeur.

Face à une demande urgente, interrompez le parcours proposé dans le message. Ouvrez vous-même votre espace officiel ou utilisez une coordonnée publiée par l’administration. Ne transmettez pas un code de connexion à une personne qui vous contacte en prétendant résoudre un incident.

## Préparer une consigne pour la messagerie

Convenez de la personne qui examine les alertes fiscales et du canal utilisé pour interroger l’administration. La consigne doit être connue de l’accueil et des remplaçants, car ces messages peuvent arriver pendant une absence.

Conservez les messages suspects avec les éléments utiles, sans multiplier les transferts de pièces sensibles. Si une action a déjà eu lieu, notez précisément ce qui a été communiqué ou effectué. Le responsable peut alors demander l’aide adaptée sans reconstruire le dossier à partir de souvenirs.

## Checklist face à un message fiscal inhabituel

1. Lire la demande sans activer immédiatement un lien ou une pièce jointe.
2. Vérifier si l’information apparaît dans l’espace officiel consulté directement.
3. Utiliser un contact administratif obtenu indépendamment du message.
4. Suspendre les paiements et transmissions inhabituels jusqu’à clarification.
5. Conserver les faits, les dates et les références nécessaires au signalement.
6. Informer le responsable si des données ou des accès ont déjà été transmis.

## Exemple fictif : une référence d’entreprise exacte

Une TPE reçoit un courriel mentionnant son SIREN et demandant une validation urgente. L’assistante ne considère pas cette référence comme une preuve d’identité. Elle vérifie le dossier par le canal officiel, puis transmet le résultat au dirigeant. Cette situation est inventée.

Cet article rapporte l’état de l’annonce d’août. Pour connaître les informations actualisées ou la situation de votre dossier, consultez les communications officielles et votre interlocuteur administratif.

## S34 — Marchés publics : préparer les preuves environnementales

Actualité : 2026-08-21. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/marches-publics-criteres-environnementaux-aout-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/marches-publics-criteres-environnementaux-aout-2026).

Depuis le 21 août 2026, de nouvelles exigences environnementales concernent les marchés publics. Lisez les critères et préparez des justificatifs adaptés au dossier.

La publication de Service Public Entreprendre du 18 août 2026 présente de nouvelles exigences environnementales applicables aux marchés publics à partir du 21 août. Elle décrit notamment un critère d’attribution et une condition d’exécution prenant en compte l’environnement.

Pour une entreprise candidate, le travail commence par la lecture du dossier de consultation. Les exigences doivent être comprises à partir de l’objet du marché et des documents de l’acheteur, sans inventer une certification obligatoire pour toutes les réponses.

## Ce que cela change pour vous

Repérez ce qui sert à noter l’offre et ce qui devra être respecté pendant l’exécution. Une déclaration générale d’intention ne répond pas nécessairement à un critère demandant des moyens ou des résultats précis.

La date de la consultation compte également : les marchés engagés avant le nouveau cadre peuvent suivre les règles transitoires décrites dans la source. Ne modifiez pas une candidature ou un contrat ancien sur la seule base de la date d’août sans vérifier sa situation.

## Constituer un dossier de preuves pertinentes

Associez chaque exigence aux pièces que l’entreprise possède réellement : méthode de livraison, caractéristiques d’un produit ou organisation d’une prestation, selon ce que demande le marché. Vérifiez la date, la portée et le titulaire de chaque justificatif.

L’assistante peut préparer un tableau « exigence — réponse — preuve — responsable ». Le dirigeant et les spécialistes concernés valident les engagements. Aucun indicateur ni résultat environnemental ne doit être inventé pour compléter une case.

## Checklist de réponse au marché

1. Relever la date de consultation et les dispositions applicables.
2. Identifier le critère environnemental utilisé pour l’attribution.
3. Séparer les conditions à respecter pendant l’exécution.
4. Rassembler les preuves correspondant exactement aux demandes.
5. Faire valider les engagements, leur faisabilité et les pièces associées.
6. Vérifier les versions et conserver le dossier réellement déposé.

## Exemple fictif : une demande sur les livraisons

Une entreprise répond à une consultation qui examine l’organisation des livraisons. Son assistante rassemble les informations existantes sur les trajets et les moyens utilisés. Le responsable valide une réponse conforme à la pratique réelle, sans ajouter de pourcentage d’économie non mesuré. Ce cas est inventé.

Après attribution, transférez les engagements retenus dans le dossier opérationnel. Une promesse contenue dans l’offre doit être connue des personnes chargées de réaliser la prestation, avec les preuves que le contrat demandera.

Utilisez-le avec les décisions confirmées par vos interlocuteurs, puis attribuez une prochaine action aux points qui restent ouverts.

## S35 — Facturation : organiser le circuit après le 1er septembre

Actualité : 2026-09-01. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/facturation-electronique-premiere-semaine-septembre-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/facturation-electronique-premiere-semaine-septembre-2026).

La réception électronique a démarré en septembre 2026 pour les entreprises concernées. Vérifiez les accès, les notifications et le suivi des factures reçues.

Le 1er septembre 2026 marque le démarrage de la facturation électronique selon le calendrier de la réforme. Le communiqué ministériel rappelle la réception pour les entreprises assujetties concernées et l’émission par les grandes entreprises et les ETI à cette étape.

Pour les PME et microentreprises, le calendrier d’émission prévoit le 1er septembre 2027. Ce décalage ne signifie pas qu’une petite entreprise concernée peut attendre 2027 pour organiser la réception.

## Ce que cela change pour vous

Une facture peut arriver dans un circuit différent de l’ancienne boîte de réception. Il faut savoir qui la voit, comment elle est attribuée et ce qui permet de la rapprocher d’une commande ou d’un paiement.

Le ministère annonce qu’aucune entreprise ne sera sanctionnée en 2026 lors de ce démarrage. Cette priorité à l’accompagnement ne remplace pas la mise en place du circuit. Vérifiez avec votre comptable le périmètre de vos opérations et vos échéances au lieu de généraliser le calendrier à toutes les factures sans distinction.

## Faire une revue des premières réceptions

Prenez quelques dossiers réellement reçus et vérifiez leur chemin : notification, lecture, traitement, transmission comptable et classement. Repérez les doubles arrivées, les pièces manquantes et les factures encore visibles seulement dans un ancien outil.

L’assistante peut préparer le suivi et les demandes au support. Le dirigeant valide les décisions de paiement ; le cabinet comptable examine les traitements fiscaux et comptables. Une facture reçue ne doit pas être payée simplement parce qu’elle apparaît dans la plateforme.

## Checklist du circuit de réception

1. Vérifier l’accès effectif de l’entreprise à sa plateforme.
2. Désigner la personne qui suit les nouvelles factures et son remplaçant.
3. Tester les notifications et l’accès aux pièces.
4. Rapprocher les factures des commandes et signaler les anomalies.
5. Confirmer la transmission au comptable et la conservation des documents.
6. Suivre les incidents avec leur date, leur responsable et leur résolution.

## Exemple fictif : deux versions d’une facture

Une TPE reçoit un document par courriel puis voit la même facture dans son nouveau circuit. L’assistante rapproche les références et signale le doublon au responsable avant le paiement. Le dossier conserve une trace du traitement retenu. Cette situation est inventée.

Au début de la réforme, une revue courte et régulière des dossiers en attente peut suffire à repérer les étapes mal comprises. Ajustez les consignes à partir des incidents constatés, sans multiplier les outils de suivi.

## S36 — Données de santé : limiter les accès et préparer l’alerte

Actualité : 2026-09-03. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/donnees-sante-habilitations-alerte-septembre-2026.md). [Aperçu local](http://127.0.0.1:4322/articles/donnees-sante-habilitations-alerte-septembre-2026).

Une sanction CNIL rendue publique en septembre 2026 rappelle les risques des accès étendus. Préparez le dossier des habilitations et le circuit d’incident.

Le 3 septembre 2026, la CNIL a rendu publique une sanction de 500 000 euros concernant l’Hôpital privé de la Loire après une violation de données. La publication met en lumière plusieurs faiblesses du système et de la gestion de l’incident.

La décision concerne cet établissement et son contexte. Elle fournit néanmoins des points de vigilance pour les organismes qui traitent des documents sensibles, sans autoriser une transposition automatique de toutes ses mesures à une autre structure.

## Ce que cela change pour vous

La CNIL relève notamment des accès externes insuffisamment protégés et des droits trop étendus. Elle décrit aussi une détection trop tardive d’activités anormales et une information qui n’avait pas couvert toutes les personnes concernées.

Avant de déléguer une tâche administrative, définissez les documents réellement nécessaires et les habilitations adaptées. Un intervenant n’a pas besoin, par défaut, d’accéder à l’ensemble des dossiers parce qu’il participe à une seule étape du traitement.

## Préparer la coordination avec les responsables

Rassemblez les personnes autorisées, leur rôle et le circuit de demande d’accès. Les protections techniques, les règles applicables aux données de santé et l’évaluation d’un incident doivent être examinées par les responsables compétents.

L’assistante peut tenir la liste des demandes, suivre les décisions et transmettre une alerte. Elle ne doit ni explorer des dossiers hors de sa mission ni déterminer seule les destinataires d’une information réglementaire après une fuite. Le circuit d’incident doit désigner celui qui prend cette décision et prévoir un relais en son absence.

## Checklist des dossiers sensibles

1. Identifier les documents et les espaces concernés.
2. Vérifier les accès internes et externes avec les responsables habilités.
3. Faire examiner les protections et les alertes par le responsable technique.
4. Limiter chaque mission aux informations nécessaires.
5. Préparer le circuit de signalement et les coordonnées des remplaçants.
6. Conserver les décisions et vérifier la fermeture des accès après une mission.

## Exemple fictif : une coordination de rendez-vous

Une structure confie une tâche de coordination à un intervenant. Elle distingue les informations de planning des documents médicaux et fait valider les accès par ses responsables. L’assistante suit les habilitations prévues pour la mission. Ce scénario est inventé ; il ne décrit pas une prestation médicale de BrittAssist.

Lorsqu’une anomalie apparaît, conservez les faits et transmettez-les rapidement. Une procédure claire permet aux responsables d’agir sans demander à une personne non habilitée de mener une enquête dans les données.

## S37 — Factures électroniques : contrôler les accès aux données

Actualité : 2026-09-10. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/cnil-facturation-electronique-donnees-personnelles.md). [Aperçu local](http://127.0.0.1:4322/articles/cnil-facturation-electronique-donnees-personnelles).

La CNIL a précisé les enjeux de données personnelles en septembre 2026. Vérifiez les comptes individuels, les habilitations et les informations des factures.

Le 10 septembre 2026, la CNIL a publié une explication des enjeux de protection des données dans la facturation électronique. La réforme concerne des documents d’entreprise, mais certaines informations peuvent identifier des personnes physiques.

La présence d’un indépendant, de coordonnées personnelles ou d’informations particulières dans une facture mérite donc un examen. Un document professionnel ne devient pas automatiquement dépourvu de données personnelles.

## Ce que cela change pour vous

La CNIL recommande aux utilisateurs de plateformes de privilégier les comptes individuels et de maîtriser les habilitations. Ces choix permettent de savoir qui intervient dans le circuit et de limiter les accès aux informations nécessaires.

Évitez le partage d’un identifiant générique entre le dirigeant, l’assistante et le comptable. Faites vérifier les possibilités de délégation et les protections proposées par la plateforme. La gestion des accès doit aussi prévoir l’arrivée, l’absence et le départ d’un intervenant.

## Examiner les informations du circuit

Regardez ce que contiennent les factures et les commentaires ajoutés pendant leur traitement. N’insérez pas dans une zone libre des informations sensibles sans nécessité. Les champs réglementaires et les modalités de traitement doivent être vérifiés par les professionnels compétents.

L’assistante peut préparer une revue des comptes et des tâches : réception, rapprochement, validation, transmission. Le dirigeant fixe les autorisations de décision ; le fournisseur explique les fonctions d’identification et d’authentification. Une fiche de délégation doit correspondre aux droits effectivement configurés.

## Checklist des accès à la plateforme

1. Recenser les personnes qui utilisent le circuit de facturation.
2. Attribuer un compte individuel lorsque la plateforme le permet.
3. Vérifier les rôles et les données accessibles pour chaque tâche.
4. Activer les protections d’authentification selon les instructions du service.
5. Examiner les commentaires et les pièces ajoutées pour éviter les informations inutiles.
6. Prévoir la modification ou la suppression des droits lors d’un changement de mission.

## Exemple fictif : un compte partagé par habitude

Une TPE utilise un seul compte pour toutes les personnes traitant les factures. Son assistante prépare la liste des tâches et demande au fournisseur les rôles disponibles. Le dirigeant valide des accès distincts avec le comptable. Cette situation est inventée et ne constitue pas un audit de conformité.

Testez ensuite les droits attribués avec les utilisateurs concernés. Un rôle correctement nommé dans un tableau peut rester mal configuré dans l’outil si personne ne vérifie son effet réel.

## S38 — TVA 2027 : préparer la fin du régime simplifié

Actualité : 2026-09-22. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/tva-fin-regime-simplifie-1er-janvier-2027.md). [Aperçu local](http://127.0.0.1:4322/articles/tva-fin-regime-simplifie-1er-janvier-2027).

La DGFiP a précisé en septembre 2026 le passage du régime simplifié aux déclarations CA3 en 2027. Préparez la périodicité et la dernière déclaration annuelle.

Le 22 septembre 2026, la DGFiP a précisé les modalités de suppression du régime simplifié d’imposition à la TVA à compter du 1er janvier 2027. Il est remplacé par le régime réel normal, avec des déclarations CA3. Le régime simplifié agricole n’est pas concerné par cette suppression.

Ce changement porte sur la TVA. Il ne faut pas en déduire automatiquement une modification de tous les régimes fiscaux de l’entreprise.

## Ce que cela change pour vous

La DGFiP indique une périodicité trimestrielle lorsque le chiffre d’affaires majoré des acquisitions taxables ne dépasse pas 1 million d’euros l’année précédente et 1,1 million pendant l’année en cours. Une option mensuelle existe ; les dépassements ont leurs conséquences propres.

La bascule est prévue automatiquement à partir des informations de la dernière déclaration annuelle. Faites néanmoins confirmer votre situation avec le comptable, notamment la clôture de l’exercice et la première période CA3 attendue. Ne reprenez pas les anciens critères de périodicité comme s’ils s’appliquaient sans changement en 2027.

## Préparer la transition avec le comptable

Pour un exercice civil, la source prévoit une dernière CA12 relative à 2026 à déposer au plus tard le 4 mai 2027, tout en organisant les déclarations du nouveau régime. Les exercices décalés suivent des modalités différentes.

Rassemblez le régime actuel, la date de clôture et les dernières déclarations. Le comptable précise les échéances et le circuit des pièces. L’assistante peut adapter le calendrier et la collecte mensuelle ou trimestrielle, sans choisir seule une option fiscale.

## Checklist avant janvier 2027

1. Retrouver le régime de TVA et la date de clôture.
2. Faire vérifier les seuils et la périodicité avec le comptable.
3. Identifier la première CA3 et la dernière déclaration annuelle attendues.
4. Préparer une collecte de pièces adaptée au nouveau rythme.
5. Faire confirmer les acomptes et paiements de transition propres à l’exercice.
6. Reporter les décisions confirmées dans l’agenda, avec leur responsable.

## Exemple fictif : un exercice civil

Une TPE actuellement au régime simplifié prépare 2027 avec son comptable. L’assistante distingue la dernière déclaration annuelle de 2026 des nouvelles périodes CA3 et organise les pièces selon le calendrier confirmé. Ce scénario inventé ne détermine pas la périodicité d’une entreprise réelle.

Gardez les échanges de confirmation avec le calendrier. Si une notification administrative semble différente, transmettez-la au comptable avant de modifier les échéances déjà préparées.

## S39 — France Num 2026 : choisir un usage concret de l’IA

Actualité : 2026-09-28. Circuit : standard. [Fiche Markdown](../../src/content/articles/barometre-france-num-2026-ia-tpe.md). [Aperçu local](http://127.0.0.1:4322/articles/barometre-france-num-2026-ia-tpe).

Le baromètre présenté en septembre 2026 montre une progression de l’IA dans les petites entreprises. Choisissez un essai utile, avec des données adaptées et une revue humaine.

Le 28 septembre 2026, la Direction générale des Entreprises a présenté le baromètre France Num 2026. La part des TPE-PME déclarant utiliser l’intelligence artificielle atteint 40 %, en progression de 14 points sur un an.

Cette observation décrit des usages. Elle ne démontre pas qu’une entreprise doit s’équiper immédiatement ni qu’un outil lui fera gagner un temps ou un montant déterminé. Le choix dépend de la tâche, des données et des vérifications nécessaires.

## Ce que cela change pour vous

Commencez par un besoin limité : reformuler un message, préparer une trame de compte rendu ou classer des informations non sensibles. Décrivez ce que vous attendez et ce qui doit être contrôlé avant utilisation.

Un essai utile peut aussi conclure que l’outil n’apporte pas assez d’aide. Si la vérification prend autant de temps que la rédaction initiale, ou si le texte demande trop de corrections, conservez ce résultat. Le baromètre ne remplace pas l’examen de votre propre fonctionnement.

## Préparer un essai avec une règle de relecture

Utilisez d’abord des données fictives ou des documents autorisés pour cet usage. Évitez de copier un dossier client confidentiel dans un service sans avoir examiné ses conditions. La personne qui valide le résultat doit connaître la source des informations et les limites de l’outil.

Comparez ensuite quelques réalisations avec la méthode habituelle : qualité, temps de correction et erreurs observées. Notez les tâches pour lesquelles l’outil aide réellement et celles qui doivent rester traitées autrement. L’assistante peut préparer l’essai et la synthèse ; le dirigeant décide de l’usage retenu.

## Checklist d’un premier essai d’IA

1. Choisir une tâche précise avec un résultat attendu.
2. Préparer des données adaptées et autorisées.
3. Lire les conditions du service et définir les informations à exclure.
4. Désigner la personne chargée de vérifier le résultat.
5. Mesurer les corrections et les erreurs, sans annoncer de gain non constaté.
6. Décider de poursuivre, d’ajuster ou d’arrêter l’essai à partir des observations.

## Exemple fictif : une trame de compte rendu

Une dirigeante teste un outil pour préparer la structure d’un compte rendu à partir d’un scénario fictif. Son assistante vérifie les rubriques et repère des formulations imprécises. Le modèle retenu est ensuite relu avant chaque utilisation avec des informations autorisées. Ce scénario est inventé.

Conservez les consignes et la décision de l’essai. Un outil adopté pour une tâche limitée ne doit pas être utilisé ensuite sur tous les dossiers par simple habitude.

## S40 — Cybermois 2026 : préparer le suivi après une fuite

Actualité : 2026-10-01. Circuit : standard. [Fiche Markdown](../../src/content/articles/cybermois-2026-suivi-fuite-donnees.md). [Aperçu local](http://127.0.0.1:4322/articles/cybermois-2026-suivi-fuite-donnees).

La CNIL et Cybermalveillance ont publié un support pratique le 1er octobre 2026. Préparez les contacts et le suivi des actions après une fuite de données.

Le 1er octobre 2026, à l’occasion du Cybermois, la CNIL et Cybermalveillance.gouv.fr ont présenté un nouveau support pratique pour les personnes victimes d’une violation de données. Il propose un suivi des actions depuis la découverte jusqu’à trente jours après.

Cette ressource s’adresse aux personnes concernées par la fuite. Elle ne remplace pas les procédures réglementaires de l’organisme qui traite les données ni l’analyse de son responsable en cas d’incident.

## Ce que cela change pour vous

Une alerte ne se termine pas au premier message reçu. Les contacts, les réponses et les actions de protection peuvent se poursuivre pendant plusieurs jours. L’entreprise peut préparer un dossier de suivi pour éviter de perdre les informations et de recommencer la même vérification.

Choisissez une méthode simple : date de découverte, source de l’alerte, interlocuteur officiel, action décidée et état. Limitez les données personnelles reprises dans ce tableau. Le document de suivi ne doit pas devenir une nouvelle copie complète des informations qui ont été exposées.

## Préparer les contacts avant l’incident

Retrouvez les coordonnées du support informatique, des responsables internes et des services officiels utiles. Conservez un moyen de les consulter si la messagerie habituelle est indisponible. Précisez qui peut agir et qui doit être informé.

L’assistante peut préparer cette organisation et suivre les réponses. Les décisions techniques et la qualification d’une violation appartiennent aux responsables compétents. Pour une personne qui reçoit une alerte, les consignes actualisées du support officiel doivent guider les démarches propres à sa situation.

## Checklist du dossier de suivi

1. Identifier la source de l’alerte et la vérifier par un canal indépendant.
2. Noter les faits et les dates sans ajouter de conclusions non établies.
3. Transmettre au responsable désigné et conserver ses instructions.
4. Attribuer un responsable aux actions et aux réponses attendues.
5. Faire des points de suivi jusqu’à la clôture des démarches décidées.
6. Classer les preuves utiles et supprimer les copies inutiles selon les règles retenues.

## Exemple fictif : plusieurs messages après une alerte

Une indépendante reçoit une notification puis plusieurs messages prétendant l’aider. Son assistante distingue l’information officielle des offres non sollicitées et tient la liste des démarches confirmées. Les décisions sont prises à partir des réponses obtenues par les canaux vérifiés. Ce cas est inventé.

Le dépliant publié pendant le Cybermois peut servir de support à une discussion d’équipe. Prévoyez une lecture concrète : où se trouvent les contacts, qui reçoit une alerte et comment suivre une action jusqu’à sa fin.

## S41 — DGFiP : un numéro unique pour les professionnels

Actualité : 2026-10-08. Circuit : reglementaire. [Fiche Markdown](../../src/content/articles/numero-unique-dgfip-professionnels.md). [Aperçu local](http://127.0.0.1:4322/articles/numero-unique-dgfip-professionnels).

Depuis le 8 octobre 2026, le 0 806 807 807 accueille les questions des professionnels. Préparez vos références et gardez une trace écrite des demandes importantes.

Le 8 octobre 2026, la DGFiP a annoncé l’extension du 0 806 807 807 comme numéro national d’accueil des professionnels. Initialement consacré à la facturation électronique, il permet désormais d’aborder les questions fiscales courantes de l’entreprise.

Le service est annoncé gratuit, hors coût de l’appel. Les horaires communiqués sont du lundi au vendredi, de 8 h 30 à 18 h, en horaires métropolitains. Le dispositif couvre aussi les entreprises d’outre-mer.

## Ce que cela change pour vous

Un numéro identifié facilite la préparation d’une question sur la TVA, les impôts professionnels ou les services en ligne. Les questions de facturation électronique conservent un choix dédié, annoncé comme le choix 1 du menu vocal.

Un dossier demandant un examen plus approfondi peut être orienté vers le service des impôts des entreprises. L’existence du numéro ne garantit donc ni une résolution immédiate ni un appel aboutissant du premier coup. Le communiqué invite aussi à privilégier la messagerie sécurisée de l’espace professionnel pour les échanges appropriés.

## Préparer l’appel et la trace écrite

Rassemblez le SIREN, la référence du document et la date de l’échéance. Écrivez la question en quelques phrases. Après l’appel, notez le service contacté et les indications reçues, sans transformer une réponse générale en validation de votre situation fiscale.

Pour une demande engageant l’entreprise, faites confirmer le canal et les pièces attendues. La messagerie sécurisée permet de conserver une trace des demandes écrites. L’assistante peut préparer le dossier et intervenir dans la limite d’une délégation autorisée, sans utiliser arbitrairement les identifiants du dirigeant.

## Checklist avant de joindre la DGFiP

1. Vérifier le numéro sur une publication officielle consultée directement.
2. Retrouver les références de l’entreprise et du dossier.
3. Définir une question précise et identifier la date importante.
4. Préparer les pièces utiles sans transmettre d’informations inutiles.
5. Noter la réponse, son contexte et les démarches conseillées.
6. Conserver les échanges écrits et inscrire la prochaine action dans le calendrier.

## Exemple fictif : une question sur la TVA 2027

Une dirigeante reçoit une information sur sa périodicité de TVA. Son assistante prépare les références et la question, puis suit le canal indiqué par le service pour obtenir une confirmation adaptée au dossier. Le comptable examine la réponse avant la mise à jour du calendrier. Ce cas est inventé.

Pour éviter les faux appels, composez vous-même la coordonnée officielle. Un interlocuteur qui vous contacte ne doit pas recevoir vos codes de connexion ou de validation sur la seule foi du numéro affiché.
